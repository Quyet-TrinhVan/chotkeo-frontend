# Chốt Kèo - React Native Expo App

Ứng dụng di động "Chốt Kèo" được xây dựng bằng **React Native** và **Expo**.

## 🚀 Khởi chạy dự án

### Cài đặt dependencies

```bash
pnpm install
# hoặc: npm install / yarn install
```

### Chạy ứng dụng

- **Chạy Expo Metro Bundler (mặc định):**
  ```bash
  pnpm start
  ```
  *(Dùng ứng dụng Expo Go trên điện thoại iOS / Android để quét mã QR và trải nghiệm ngay)*

- **Chạy trên iOS Simulator:**
  ```bash
  pnpm ios
  ```

- **Chạy trên Android Emulator:**
  ```bash
  pnpm android
  ```

- **Chạy trên Web Browser:**
  ```bash
  pnpm web
  ```

### Kiểm tra TypeScript

```bash
pnpm run lint
```
